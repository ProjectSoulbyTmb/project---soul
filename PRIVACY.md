# Eidovara privacy notice

Last updated: August 21, 2026

Eidovara stores profiles, conversations, memories, preferences, local safety records, settings, and backups in the Windows application-data directory. Official Windows builds protect this data with the current Windows user's operating-system credential encryption when available. This protects data at rest, not against malware or another process already running as that user. Credentials are encrypted separately and are not exposed to the renderer. Protected backups may be bound to the same Windows account.

Eidovara has no owner-operated accounts, telemetry, advertising identifier, analytics SDK, cloud memory, or automatic conversation reporting. Network access is user-directed except for the official update-manifest check. A configured model or search provider receives the content or search terms needed for the request under that provider's terms. External links and media services operate under their own privacy terms. See `NETWORK-USAGE.md` for the connection list.

Users can inspect, back up, reset, or delete local data. Eidovara is restricted to users age 18 or older and does not intentionally collect minors' personal information. Its local age confirmation is not independent age or identity verification. Adult Mode additionally requires the user to have reached the age of majority where located.

This notice describes the current release, not an independent audit or universal compliance certification. Accounts, telemetry, cloud storage, payments, or user uploads require a new privacy and child-safety review before launch.

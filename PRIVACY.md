# Eidovara Privacy Declaration

Eidovara has no telemetry, advertising identifier, analytics SDK, or automatic conversation-reporting service. Profiles, memories, conversations, relationship state, safety audit entries, settings, and backups remain in the operating system application-data directory unless the user deliberately moves or shares them. Official Windows desktop builds protect these files with the current Windows user's operating-system credential encryption when available; this protects data at rest but not against malware or another process already running as that user.

Network access is request-driven except for a lightweight update-manifest check in official release builds. A model provider receives conversation context only after the user configures and selects that provider. Public research sends the user's search terms to the selected knowledge/media or broad-search service. Clicking Spotify, YouTube, a source link, or an update installer transfers control to that external service and its privacy terms.

Secrets are separately encrypted with the operating system credential-protection facility when available and are never exposed to the renderer. Protected backups are device/user-bound and are not portable to a different Windows account without a future explicit export feature. Eidovara does not silently send local safety reports or accusations to third parties. Users can inspect, back up, reset, or delete local application data.

This is a self-declaration describing the software behavior, not an independent privacy audit or government certification.

Eidovara is a general-audience desktop application and is not directed to children under 13. It does not provide an owner-operated account system or intentionally collect children's personal information. Adult Soul features require the user's adult-status confirmation and current consent. A future website account, telemetry, cloud memory, payment identity, or user-content service must receive a new privacy and child-safety review before launch.

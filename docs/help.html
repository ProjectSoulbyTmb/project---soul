Help / FAQ · v0.18.0

Install, connect, and stay local-first.

This FAQ matches advertised Eidovara limits. Ask Eidovara in the corner uses the same facts. It is not legal advice.

How do I install Eidovara?

Use GitHub Releases for Eidovara-*-Windows-x64-Setup.exe when published, or on Windows run npm run dist:win:installer. Adults 18+ only. Official platform is Windows 10/11 x64.

What is the age gate?

You must be 18 or older. Setup shows an 18+ notice. The desktop app blocks use until you confirm age and accept the Terms. The CLI needs --i-am-18-or-older or a stored confirmation. Local confirmation is not independent identity verification.

How do I Connect a service in Settings?

After the 18+ gate, Settings → Eidovara service (or Ctrl+A Test service). Paste an HTTPS base. The app calls /health, /v1/config, and /v1/status only. Conversations are not sent. No Worker URL is compiled into the app. If the service is down, the local workspace still works.

Does Offline Soul need the internet?

No. Free / Offline Soul works with no cloud URL. Conversations stay on the PC. Explicit internet/web/online research is optional and only after you ask.

Can I pay for Premium here?

No. Payments are off. v0.18.0 does not sell Premium. There is no live checkout. Premium can be tested locally with Ctrl+A; that is not payment or PCI processing.

Why is the installer unsigned?

Official advertised builds are Authenticode-unsigned. SmartScreen may warn. Verify SHA-256 and GitHub provenance. Provenance is not Authenticode. There is no official Linux or macOS product.

Is this website Soul?

No. This site explains and distributes the Windows app. Ask Eidovara is a website helper over a knowledge pack, not desktop Soul and not a consciousness claim.

The product is the Windows app, not this page.

Install the official unsigned Windows Alpha to use apps, media, research, backups, and optional Soul on your PC. Free / Offline Soul works with no cloud URL. This site’s helper is not Soul.

Apps & gaming

Discover local Start Menu shortcuts, confirm, then ask Windows to launch them. Free keeps up to three apps. Gaming mode reduces Eidovara visuals only. No process injection or anti-cheat interaction.

Media

Play user-selected local files and properly sourced public audio or video. Official Spotify/YouTube HTTPS searches. Neural TTS, VRM, and OBS websocket control are not bundled.

Research

On an explicit internet request, cited Wikipedia/Wikimedia results, or a secure page in the system browser. Broad keyed Brave Search is a Premium test gate.

Private continuity

Preferences, conversations, backups, and appearance stay local by default. Encrypted settings use Windows credential protection when available.

Optional Soul

Tone, memory, voice, and avatar — or the modules with no remote model. Soul is software, not a consciousness claim.

Optional service

After 18+, Settings → Eidovara service can call /health, /v1/config, and /v1/status only. Conversations are not sent. If the service is down, the local workspace still works.

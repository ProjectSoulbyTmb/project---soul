Advertised v0.19.0 workspace

The product is the Windows app, not this page.

This site describes the advertised desktop workspace. It does not reimplement Apps, media playback, Soul, or Settings in the browser. Install the official unsigned Windows Alpha Eidovara-0.19.0-Windows-x64-Setup.exe (18+, about 101.3 MiB) to use those surfaces on your PC. Free / Offline Soul works with no cloud URL.

Apps & gaming

Discover local Start Menu shortcuts, organize trusted .exe/.lnk files, confirm, then ask Windows to launch them. Free keeps up to three apps. Low-overhead gaming mode reduces Eidovara visuals only. No process injection or anti-cheat interaction.

Media & entertainment

Play user-selected local files and properly sourced public audio or video, keep queues and favorites, and open official Spotify/YouTube HTTPS searches. Playback can require confirmation. Neural TTS, VRM, and OBS websocket control are not bundled.

Research

On an explicit internet, web, or online request, retrieve cited Wikipedia/Wikimedia results (pictures, audio, and video when asked), or open secure pages in the system browser. Broad keyed Brave Search is a Premium test gate.

Private continuity

Keep reviewable preferences, conversations, backups, appearance, and workspace configuration local by default. Encrypted settings use Windows credential protection when available.

Optional Soul

Configurable tone, focus, memory, voice, avatar, and initiative — or use the modules without a remote model. Soul is software, not a consciousness claim. This website helper is also not Soul.

Settings → Eidovara service

After the 18+ gate, the desktop defaults to https://api.eidovara.org. Paste another HTTPS base to override. The app calls /health, /v1/config, and /v1/status only. Conversations are not sent. No workers.dev host is compiled in. If the service is down, the local workspace still works.

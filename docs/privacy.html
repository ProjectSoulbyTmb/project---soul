Privacy notice

Eidovara stores profile data locally by default. Network requests occur when a user requests internet research, opens an external link, checks for updates, or configures a model or search provider. Provider services receive the information required to fulfill the request under their own terms. The application does not collect card numbers or security codes. Review and remove local memories, credentials, backups, and application shortcuts from the desktop application.

Eidovara is a general-audience desktop application and is not directed to children under 13. The current project does not operate user accounts or intentionally collect children's personal information. Adult features require adult-status confirmation and current consent.

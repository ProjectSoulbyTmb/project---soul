Age statement

Eidovara is for adults 18+.

Requirement

You must be at least 18 years old to download, install, or use Eidovara. If you are under 18, leave this site and do not install the software.

How it is enforced

This website’s Download page requires a local 18+ checkbox before installer links work. Windows Setup shows an 18+ installer notice. The desktop app blocks use until you confirm age and accept the terms; declining exits. The CLI refuses product commands unless you pass --i-am-18-or-older or a prior confirmation is stored in the data directory. Adult Mode is a separate triple gate and stays off by default.

Limits

Local confirmation is not independent identity or age verification and is not a COPPA or age-assurance certification. The project does not operate user accounts and does not intentionally collect personal information from children.

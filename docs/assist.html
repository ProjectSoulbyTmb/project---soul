Website helper · not Soul

Ask Eidovara on this site.

The floating Ask Eidovara button is a website helper for visitors. It answers from a fixed knowledge pack built from the README, Terms, Age, Privacy, and download facts. It is not desktop Soul, not conscious, and not legal advice. Adults 18+.

On GitHub Pages (no secrets)

The helper runs in your browser over knowledge.js. No API key. If JavaScript is off, use Help / FAQ instead. Modes inside the same widget: Help, Download help, and Legal pointers — not two competing products.

Optional online path

If you paste an HTTPS Worker base (same pattern as the desktop), the widget may POST /v1/assist. Answers still come from the same allowlisted pack. Transcripts are not stored. Desktop conversation history is never sent. If no URL is configured, or the fetch fails, the on-page pack still works.

No workers.dev host is compiled into this site. Payments stay off. Criminal or unauthorized-access coaching is refused.

Status

Website helper · not Soul

Ask about the public site, not a hosted assistant.

The Ask Eidovara button (and this page) answers from a fixed knowledge pack built from README, Terms, Age, Privacy, and download facts. It is not Soul, not conscious, and not legal, medical, or financial advice. Adults 18+. Conversations are not stored.

Works on GitHub Pages

No API key is required. Answers run in your browser from knowledge.js. Use Help, Download help, or Legal pointers. Legal mode still is not legal advice.

Optional Worker

If you operate a Worker, paste an HTTPS base in the helper sheet or on Status (saved in this browser’s localStorage as eidovara.serviceBase). The site may POST a single question to /v1/assist. Desktop conversation history is refused. No workers.dev host is compiled into this page.

Not the desktop product

Soul, apps, media, and memories run in the Windows app. This helper cannot launch .exe files, play your library, or replace Settings → Eidovara service.

What it will refuse

Criminal activity, unauthorized access, and bypassing security controls. It will not invent Authenticode, live checkout, official Linux/macOS products, or consciousness claims.

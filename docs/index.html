Get Eidovara · Windows 10/11 x64 · 18+

Install the desktop app. Keep Soul on your PC.

The product is the Windows application, not a multi-tenant web service. Conversations, memories, and workspace settings stay local by default. The desktop app can attach to the online Eidovara service for status and config while remaining local-first; you never need that attachment to use Free / Offline Soul. Adults 18+ only. Official installers are Authenticode-unsigned.

1

Download the official Windows installer

The advertised download is Eidovara-0.19.0-Windows-x64-Setup.exe — the unsigned NSIS .exe (about 101.3 MiB) from GitHub Releases, not the source repository. Confirm 18+ on Download, then get that file. Windows SmartScreen may warn; verify SHA-256 EF228574DCDF34B8A9039654F2B762FAB6D289CCA9A94B2ECCF048AE971FE711. Adults 18+.

2

Or build from source

Cloning the GitHub repo is a fallback, not the primary download. On Windows 10/11 x64 you can run npm run dist:win:installer. Official advertised distribution is Windows only. Linux/macOS scripts are development targets, not products.

3

Cloud is optional config, not the app

No account is created by visiting this site. There is no live checkout. After the 18+ gate, Settings → Eidovara service defaults to https://api.eidovara.org for /health, /v1/config, and /v1/status only. Paste another HTTPS base to override. If that service is down, the local workspace still works. Conversations are not sent. No workers.dev host is compiled into the app.

Independent modules · one workspace

Useful with or without a connected assistant.

01

Apps & gaming

Discover local Start Menu shortcuts, organize trusted .exe/.lnk files, confirm, then ask Windows to launch them. Free keeps up to three apps. Low-overhead gaming mode reduces Eidovara visuals only. No process injection or anti-cheat interaction.

02

Media & entertainment

Play user-selected local files and properly sourced public audio or video, keep queues and favorites, and open official Spotify/YouTube HTTPS searches. Playback can require confirmation.

03

Research & web handoff

On an explicit internet, web, or online request, retrieve cited Wikipedia/Wikimedia results (pictures, audio, and video when asked), or open secure pages in the system browser. Broad keyed search is Premium.

04

Private continuity

Keep reviewable preferences, conversations, backups, appearance, and workspace configuration local by default.

05

Optional Soul assistance

Use configurable tone, focus, memory, voice, avatar, and initiative controls—or use the workspace modules without a remote model provider. Soul is software, not a consciousness claim.

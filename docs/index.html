Get Eidovara · Windows 10/11 x64 · 18+

Install the desktop app. Keep Soul on your PC.

Confirm 18+ on Download, then get the official installer. The desktop app can attach to the online Eidovara service for status only; you never need that to use Free / Offline Soul. Official installers are Authenticode-unsigned.

1

Official Windows installer

Download Eidovara-0.18.2-Windows-x64-Setup.exe after the 18+ gate. That .exe is the product, not the git repo. SmartScreen may warn; verify the SHA-256 below.

2

Or build from source

A fallback, not the primary download. On Windows 10/11 x64: npm run dist:win:installer. Linux/macOS scripts are development targets, not products.

3

Cloud is optional

No account from visiting this site. After 18+, Settings can attach for /health, /v1/config, and /v1/status only. Conversations are not sent.

One workspace

Useful with or without a connected assistant.

01

Apps & gaming

Discover local Start Menu shortcuts, confirm, then ask Windows to launch them. Free keeps up to three apps. Gaming mode reduces Eidovara visuals only—no process injection or anti-cheat interaction.

02

Media

Play local files you choose, plus properly sourced public audio or video. Official Spotify/YouTube HTTPS searches. Playback can require confirmation.

03

Research

On an explicit internet request, cited Wikipedia/Wikimedia results, or a secure page in your browser. Broad keyed search is Premium.

04

Private continuity

Preferences, conversations, backups, and appearance stay local by default.

05

Optional Soul

Tone, memory, voice, and avatar controls—or use the workspace with no remote model. Soul is software, not a consciousness claim. This site’s helper is not Soul.

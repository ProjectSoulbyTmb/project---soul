Get Eidovara · Windows 10/11 x64 · 18+

Install the desktop app. Keep Soul on your PC.

The product is the Windows application, not a multi-tenant web service. Conversations, memories, and workspace settings stay local by default. The desktop app can attach to the online Eidovara service for status and config while remaining local-first; you never need that attachment to use Free / Offline Soul.

1

Download the unsigned Stable Alpha

When a GitHub Release includes Eidovara-*-Windows-x64-Setup.exe, get it from the Releases page. That installer is Authenticode-unsigned. Windows SmartScreen may warn; verify SHA-256 and GitHub provenance. Adults 18+ only.

2

Or build from source

If no Setup.exe is listed yet, clone the source-available repository and run npm run dist:win:installer on Windows 10/11 x64. Official advertised distribution is Windows only. Linux/macOS scripts are development targets, not products.

3

Cloud is optional config, not the app

No account is created by visiting this site. There is no live checkout. After the 18+ gate, Settings → Eidovara service (or Ctrl+A Test service) can attach for /health, /v1/config, and /v1/status only. If that service is down, the local workspace still works. Conversations are not sent. The Worker URL is not compiled into the app.

Independent modules · one workspace

Useful with or without a connected assistant.

01

Apps & gaming

Discover local Start Menu shortcuts, organize trusted .exe/.lnk files, confirm, then ask Windows to launch them. Free keeps up to three apps. Low-overhead gaming mode reduces Eidovara visuals only. No process injection or anti-cheat interaction.

02

Media & entertainment

Play user-selected local files and properly sourced public audio or video, keep queues and favorites, and open official Spotify/YouTube HTTPS searches. Playback can require confirmation.

03

Research & web handoff

On an explicit internet, web, or online request, retrieve cited Wikipedia/Wikimedia results (pictures, audio, and video when asked), or open secure pages in the system browser. Broad keyed search is Premium.

04

Private continuity

Keep reviewable preferences, conversations, backups, appearance, and workspace configuration local by default.

05

Optional Soul assistance

Use configurable tone, focus, memory, voice, avatar, and initiative controls—or use the workspace modules without a remote model provider.

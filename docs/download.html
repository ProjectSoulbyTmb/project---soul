Windows 10/11 x64 · Authenticode-unsigned · 18+

Get the desktop app, not a web account.

Eidovara is a local-first Windows desktop workspace. Confirm you are 18 or older before using the download links. There is no live checkout. Linux and macOS scripts are not official products.

Adult gate

If you are under 18, leave this page and do not install Eidovara. Read Age 18+ and Terms first. Local confirmation is not independent identity verification.

Download Windows Alpha (18+) View source

The installer is Authenticode-unsigned. Windows SmartScreen may warn. Verify SHA-256 (SHA256SUMS.txt) and GitHub/Sigstore provenance. Provenance is not Authenticode.

If no Setup.exe is listed

Build on Windows 10/11 x64 from the source-available repository:

npm install
npm run dist:win:installer

The installer is generated in dist/. Node 20 runs tests; Electron 43 packaging needs Node >= 22.12.0.

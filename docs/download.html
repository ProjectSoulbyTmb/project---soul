Windows 10/11 x64 · Stable Alpha · 18+

Get the unsigned Windows installer.

Official advertised distribution is Authenticode-unsigned. Windows SmartScreen may warn. Verify SHA-256 checksums and GitHub/Sigstore provenance. Provenance is not Authenticode. Adults 18+ only. There is no live checkout on this page.

Confirm you are 18 or older and that you accept the Terms before using the download links. Local confirmation is not independent identity verification.

Download unsigned Setup.exe View source Age 18+ statement
1

GitHub Releases

When a Release includes Eidovara-*-Windows-x64-Setup.exe, get it from the official Releases page only. A v0.18.0 installer may already be listed. Do not download Setup.exe from third-party mirrors.

2

Build from source

If no Setup.exe is listed yet, clone the source-available repository on Windows 10/11 x64, run npm install, then npm run dist:win:installer. Linux/macOS scripts are development targets, not official products.

3

Then use the desktop app

The workspace lives on your PC. After the in-app 18+ gate, Settings → Eidovara service can attach for /health, /v1/config, and /v1/status. Conversations stay local. No Worker URL is compiled in.

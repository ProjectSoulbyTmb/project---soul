Frequently asked

Straight answers for v0.19.0.

These answers match the advertised Windows product. They are not legal advice. Use Ask Eidovara for the same knowledge pack.

What is Eidovara?

A local-first Windows 10/11 x64 desktop workspace for apps, gaming tools, media, research, backups, and optional Soul. Visiting this website does not create an account. Soul is optional software, not a consciousness claim.

How do I install Eidovara?

Confirm you are 18 or older on the Download page. After that gate, the primary button downloads the official unsigned installer Eidovara-0.19.0-Windows-x64-Setup.exe — the .exe (about 101.3 MiB), not the GitHub source tree. SHA-256 EF228574DCDF34B8A9039654F2B762FAB6D289CCA9A94B2ECCF048AE971FE711. You can still build on Windows with npm run dist:win:installer. Adults 18+.

Why does Windows warn me?

Official advertised installers are Authenticode-unsigned. They are not Microsoft-certified, EV-signed, or SmartScreen-preapproved. We cannot Authenticode-sign until the owner provides a certificate. SmartScreen may warn. Verify SHA-256 and GitHub provenance. Provenance is not Authenticode.

Is there a Linux, macOS, or iOS app?

No official Linux or macOS product. Not an iOS, iPhone, iPad, or Apple product. Linux/macOS scripts are development targets.

Is Eidovara someone else’s assistant or a film character?

No. Eidovara, Soul, and the Soul kernel are first-party software names. They are not third-party film or assistant products and are not affiliated with those owners. See Licensing and the repository trademark notice.

Do I need the cloud?

No. Free / Offline Soul works with no Worker URL. After 18+, Settings → Eidovara service defaults to https://api.eidovara.org for /health, /v1/config, and /v1/status only. Paste another HTTPS base to override. Conversations are not sent.

Can I pay for Premium here?

No. v0.19.0 does not sell Premium and does not process payments. Ctrl+A local-admin testing is not checkout or PCI processing.

What are the keyboard shortcuts?

In the Windows app after 18+: Ctrl+K jumps to Dashboard, Settings groups, Apps, Soul, and legal. Ctrl+/ opens the cheatsheet. Ctrl+A opens private admin only when you are not typing in a field. Click the Soul face or type in the right dock to ask locally. Hold the mic to dictate. Enter sends a message. Esc closes a dialog. Launching an app still asks you to confirm.

Is the website helper Soul?

No. Ask Eidovara is a website helper over a fixed knowledge pack. It is not Soul and not legal advice. Transcripts are not stored.

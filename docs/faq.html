Frequently asked questions

General

What is Eidovara?
Eidovara v1.0.0 is a local-first Windows desktop workspace (Alpha release). It includes media, research, optional Soul layer, persistent continuity, custom themes, and gaming mode. 18+ restricted source-available software.
Is Eidovara free?
Yes, v1.0.0 is a free Alpha. No payments, checkout, or subscriptions are implemented. Features are included at no cost within the 18+ framework.
What does 18+ mean?
Eidovara includes adult-oriented features, media, and research capabilities. Users must confirm they are 18 or older to access the software. This gate applies across all touchpoints: LICENSE, TERMS.md, AGE.md, CLI, kernel, and desktop UI.

Soul Layer

What is the Soul layer?
Soul is an optional assistant layer with persistent continuity, configurable personality, voice/presence, research, media, and tool support. It is software, not a consciousness claim. Triple-gate: age + enablement + consent.
Can I disable Soul?
Yes, Soul is optional. You can use the workspace entirely without the Soul layer. The desktop interface and core features remain functional.
Is Soul a conscious entity?
No. Soul is explicitly software with no consciousness claims. The project document states: "Soul is software, not consciousness."

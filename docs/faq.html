Frequently asked · current release v0.22.2

Straight answers for v0.22.2.

These answers match the published Eidovara v0.22.2 Windows release and current website knowledge. They are not legal advice.

What is Eidovara?

A local-first Windows 10/11 x64 desktop workspace for apps, gaming tools, media, internet research, backups, updates, persistent continuity, and optional Soul. Soul is optional software, not a consciousness claim.

How do I install Eidovara?

Confirm you are 18 or older on the Download page. The official installer is Eidovara-0.22.2-Windows-x64-Setup.exe, 106,691,524 bytes (about 101.75 MiB). SHA-256: F29A52F0495AB111A277780706E75ED616B6C236E25C3BDDF36E144ED5326675. It is Authenticode-unsigned. You can also build from source on Windows with npm run dist:win:installer.

Why does Windows warn me?

The v0.22.2 installer is Authenticode-unsigned and Windows SmartScreen may warn. Verify the SHA-256 on the Download page and GitHub/Sigstore build provenance. Provenance is not Authenticode signing.

Is v0.22.2 free?

Yes. v0.22.2 is currently a full free Alpha. Implemented workspace, compatible-provider, keyed research, media, backup, update, personalization, RGB, and linked-app capabilities are not blocked behind a paid entitlement. Payments, subscriptions, and checkout remain disabled.

Do I need the cloud?

No. Core workspace functions and Offline Soul can operate without the official service. Online research, updates, provider connections, and user-directed online media require network access.

What online features are in v0.22.2?

Explicit internet research with sanitized public sources, online health/status, media discovery/playback surfaces, update infrastructure, and optional provider connections. Network failures fall back to the local-first workspace where possible.

Is there a Linux, macOS, or iOS app?

The official advertised product is Windows 10/11 x64. Linux and macOS packaging scripts remain development targets. Eidovara is not an iOS product.

Is the website helper Soul?

No. Ask Eidovara is a product helper over a fixed knowledge pack. It is not Soul and does not store desktop conversation transcripts.

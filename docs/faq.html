Frequently asked · current release v0.22.2

Straight answers for the current release.

These answers match the published Eidovara v0.22.2 Windows release and the current website knowledge pack. They are not legal advice.

What is Eidovara?

A local-first Windows 10/11 x64 desktop workspace for apps, gaming tools, media, internet research, backups, updates, persistent continuity, and optional Soul. Visiting this website does not create an account. Soul is optional software, not a consciousness claim.

How do I install Eidovara?

Confirm you are 18 or older on the Download page. The official installer is Eidovara-0.22.2-Windows-x64-Setup.exe, 106,691,429 bytes (about 101.75 MiB). SHA-256: A26B8232E6B81A77566610AFF110197022850AB4348F86D390663831584B5DEE. The installer is Authenticode-unsigned. You can also build from source on Windows with npm run dist:win:installer.

Why does Windows warn me?

The current v0.22.2 installer is Authenticode-unsigned. It is not Microsoft-certified, EV-signed, or SmartScreen-preapproved. Windows SmartScreen may warn. Verify the SHA-256 on the Download page and the GitHub/Sigstore build provenance. Provenance is not Authenticode.

Is there a Linux, macOS, or iOS app?

The official advertised product is Windows 10/11 x64. Linux and macOS packaging scripts are development targets rather than official signed products. Eidovara is not an iOS, iPhone, iPad, or Apple product.

Do I need the cloud?

No. Local workspace functions and Free / Offline Soul can operate without the official service. After 18+, Settings → Eidovara service defaults to https://api.eidovara.org for health/config/status. Explicit internet research, updates, optional provider connections, and user-directed online media functions require network access.

What online features are in v0.22.2?

v0.22.2 includes explicit internet research with cited and sanitized public sources, online heartbeat/status, media discovery and playback surfaces, update infrastructure, and optional provider connections. Network failures are designed to fall back to the local-first workspace instead of stopping the app.

Can I pay for Premium here?

No. v0.22.2 does not process payments and no live checkout is enabled. Premium feature gates are available only for local administrator testing in the current release.

What are the keyboard shortcuts?

In the Windows app after 18+: Ctrl+K opens navigation/search, Ctrl+/ opens the cheatsheet, and Ctrl+A opens the private administrator panel when you are not typing in a field. Enter sends a Soul message where applicable. Esc closes dialogs. Launching an application still requires confirmation.

Is the website helper Soul?

No. Ask Eidovara is a website helper over a fixed product knowledge pack. It is not Soul, does not store conversation transcripts, and is not legal, medical, or financial advice.

Why might the live website look older than the repository?

The official site is deployed from the docs/ folder on main. GitHub Pages mirrors the same source, and the Cloudflare Pages production workflow deploys website updates from main when production credentials are configured. Browser or edge caching can briefly show older content after a deployment.

Eidovara v1.0.0 is the current **local-first Windows desktop release**. Making it online for users means a public HTTPS website, the published Windows installer, optional service health/config/status, user-directed internet research/media/provider access, and update delivery. It does **not** mean hosting everyone's Soul, conversations, or memories in a central account service.
